Support

Everything below is about the iPhone app "Untracable AI". If your question is not answered here, email sivavimelrajhen@gmail.com and include your iPhone model and iOS version — it makes a fix far quicker.

Getting started

There is no setup. The model is already inside the app, so the first launch simply loads it: you will see > loading model… under the title for a few seconds — longer on older iPhones, because roughly 770 MB has to be read from storage. When the microphone button turns green the model is ready. Type a message and send.

Nothing to download, nothing to sign into. No account, no email, no API key is needed to use the app. Turning on flight mode is a fair test: chat keeps working.

Documents and photos

Tap + → file to attach a PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), HTML, CSV, JSON, YAML, plain text or a source-code file. The text is extracted on the device, and the passage the answer drew on is shown above the reply so you can check it.

Tap + → image or camera to attach a picture. Text in the image is read and its subject matter classified on device using Apple's Vision framework, then handed to the model.

Legacy .doc, .xls and .ppt files are not supported — save them as the modern format first and try again.

Web search and the built-in browser

Search is off until you tap the globe, and it stays on only for that conversation. When it is on, your query goes from the phone to a public search engine and the results appear as cards; tap one to open it in the in-app browser. Inside the browser, the assistant button can summarise the page or answer questions about it — still using the model on your phone.

If search returns nothing: check that you have a connection, and try again in a minute. The app reads public search pages directly, and those pages occasionally change shape or rate-limit a device that is asking very quickly.

Using your own model or API key

Import a GGUF model

Tap AI → import_your_ai_model and pick a .gguf file from the Files app. Small instruct-tuned models (1–3 B, Q4) are the realistic range on a phone; larger ones may fail to load or be very slow. To copy a model onto the phone first, open Files → On My iPhone → Untracable AI and drop it there.

Connect a cloud provider

Tap AI → import_your_ai_api and choose Gemini, ChatGPT, Claude, Groq, Mistral, DeepSeek, Qwen or a custom OpenAI-compatible endpoint, then paste the key from your own account with that provider. The key is stored on your device and used only for calls to that provider. When a cloud model is selected, your prompts go to that company under their privacy policy — switch back to the local model at any time from the same sheet.

Troubleshooting

The first launch takes a long time

Expected. A large model file is being read into memory; on an iPhone with 4 GB of RAM this can take ten to twenty seconds. The spinner beside "loading model…" keeps turning while it happens.

The app closed by itself

Almost always memory pressure: iOS reclaims a large app when another app needs RAM. Close other apps and reopen it. Starting a new conversation instead of continuing a very long one also helps, since the whole conversation is held in the model's context.

Replies are slow, or slow down over a long chat

Speed depends on the iPhone's chip, and every previous turn is re-read as context, so long conversations get slower. Tap the clock icon → [new] to start a fresh session. Keeping the phone cool matters too — sustained generation makes it throttle.

The answer is wrong

A 1-billion-parameter model that fits on a phone is small. It is good at summarising, rewriting, explaining and drafting, and it is unreliable on precise facts, arithmetic and anything recent. Turn on web search for current information, attach the document you are asking about, or connect a cloud model for hard questions. Do not rely on it for medical, legal or financial decisions.

Dictation does not start

The first use asks for microphone and speech-recognition permission. If you declined, enable them in iOS Settings → Untracable AI. Dictation uses Apple's recogniser, so it also needs the keyboard language to be supported.

I want to delete everything

Delete individual sessions from the clock icon, or delete the app from the Home Screen — that removes every conversation, any imported model and any API key you stored. Nothing of yours exists anywhere else.

Privacy in one paragraph

The app has no account and no server of ours. Conversations are computed and stored on your device. Nothing is transmitted unless you turn on web search, open the browser, use dictation (which uses Apple's speech service) or connect your own cloud AI key. No analytics, no advertising, no tracking. The full policy is published separately.

One thing to be aware of. Saved conversations live in the app's folder, which is visible in the Files app under "On My iPhone" and is included in device backups. Anyone who can unlock your phone can read them, so keep a passcode on the device.

Requirements

iPhone running iOS 16.4 or later, and about 800 MB of free space for the app and its model.
